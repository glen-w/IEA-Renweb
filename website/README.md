# IEA-Renweb website

Modest public landing (plain HTML/CSS, minimal JS for mobile nav). Product
front door: hero → what the tool does → outcomes → the extract stays yours → install.

- Open `index.html` locally, or deploy via GitHub Pages (`.github/workflows/pages.yml`).
- Live path: [glenwright.earth/IEA-Renweb](https://glenwright.earth/IEA-Renweb/).
- Footer version should match [pyproject.toml](../pyproject.toml) `version` (currently **1.0.0**).
- No Sphinx guide. Docs stay Markdown in the repo; the landing links to GitHub.
- Ko-fi support link in the footer: https://ko-fi.com/C0C1XK8G
- Umami snippet uses the `IEA-Renweb` website on `analytics.glenwright.earth`. Do not reuse the glenwright.earth site id.
