IEA-Renweb

Renewable energy statistics from World Energy Balances.

Load an IEA extract into DuckDB, check the units, and calculate renewable and fossil shares. The balances stay yours. This is a library and a command line tool, not a hosted application.

See how it works Install

From an extract to shares

Two distributions of the extended World Energy Balances table. Ingest maps the older codes onto the current list.

Ingest

The fixed-width bulk file (WORLDBIG*.TXT, often in WBIG*.zip) or the long SDMX / OECD iLibrary CSV. Loading the same bytes twice is a no-op.

Compute

Total final energy consumption, renewable and fossil shares, and the power, heat, transport, buildings, industry, and agriculture splits. Shares are fractions. Energy is terajoules.

Unit check

Rows whose ktoe and TJ columns disagree, and which are not the electricity-output case, are marked suspect and left out of the calculations.

Optional extras

World Bank population, GDP, and income, and IRENASTAT capacity. They add variables. They do not change the IEA identities.

What can I do with it?

  • Load a World Energy Balances extract you already have
  • Compute one country-year, or every country-year in the warehouse
  • Validate the results and export parquet or CSV
  • Look at the warehouse in a local marimo notebook

Formulas and the unit check: methodology.

The extract stays yours

World Energy Balances is a paid IEA product. This repository is the toolset only. Do not add the balances. The warehouse is a DuckDB file outside the git tree, by default ~/Documents/renweb_data/renweb.duckdb. The notebook has no password and writes nothing: keep it on 127.0.0.1 and stop it before ingest or compute.

Install

Python 3.11 or newer, and uv. Point the commands at the files you downloaded. 

uv sync
uv run renweb ingest /path/to/WBIG1.zip
uv run renweb compute --country FRA --year 2022

Optional extras: worldbank, irena, notebook, xlsx. Details: GitHub · README
